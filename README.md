# Alieze Ignatius — Frontend Developer Portfolio

A responsive personal portfolio website built with **HTML5 and CSS3**. It introduces Alieze Ignatius as an aspiring junior frontend developer and links to public GitHub and LinkedIn profiles.

## Files

- `index.html` — semantic page structure and content
- `style.css` — responsive styling, layouts, project cards, and accessibility-focused states

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For a local development server, open the folder in VS Code and use a static server extension, or run `python -m http.server` from the folder.

## Publish with GitHub Pages

1. Open `https://github.com/igsmade/html-portfolio`.
2. Upload or replace `index.html`, `style.css`, and this `README.md` in the repository root. Keep any other files you still need.
3. Commit the changes to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then save.
7. Wait for the deployment to complete. The repository's Pages settings will show the published URL.

GitHub Pages publishes static HTML, CSS, and JavaScript files. Your repository should have `index.html` at the top level of the selected publishing source.

## Before publishing

- Confirm all profile links and project repository URLs.
- Replace project descriptions if the projects change.
- Add a professional photo only if you want one; the current design intentionally works without one.
- Add an email address only if you want it public. A public email can attract spam.
- Test navigation, keyboard focus, text contrast, and layouts at mobile and desktop widths.

## Current scope

This version intentionally uses plain HTML and CSS without a JavaScript dependency or CSS framework. It presents the owner's current stated learning focus—HTML, CSS, and JavaScript—and does not claim professional experience or advanced skills.
